# Variation Evaluation Interface 🏗️💻

A React-based dashboard for interacting with the AI Variation Evaluator.

## 🚀 Setup Instructions

1. **Install Dependencies**:

   ```bash
   npm install
   ```

2. **Run Development Server**:

   ```bash
   npm run dev
   ```

3. **Production Build**:
   ```bash
   npm run build
   ```

## 🌟 Key Components

- **Project Setup Dashboard**: Upload BOQ, Schedule, and Rate Breakdown files.
- **Variation Evaluation Chat**: AI-guided workflow for evaluating cost and time impacts.
- **Logic Visualizer**: Real-time display of CPM impacts and FIDIC 12.3 rate checks.
- **Report Center**: Preview and download generated variation proposals.

## 🛠️ Tech Stack

- **React 18** (Vite)
- **TypeScript**
- **Tailwind CSS** (Styling)
- **Axios** (API communication)
- **React Dropzone** (File uploads)
